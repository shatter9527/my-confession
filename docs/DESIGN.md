# 纪念册界面

设计参考为 [Delineate](https://delineate.appautomaton.com/)，源码见 [appautomaton/delineate](https://github.com/appautomaton/delineate)。此次从 `origin/main` 的 `9597297` 开始重构，保留中文资料、现有栏目地址和 Node/SQLite 服务。

## 从参考站到一班纪念册

| 参考站做法 | 本站实现 |
|---|---|
| 暖白纸面、深色文字、大留白 | `css/style.css` 的 paper / ink / soft / rule 变量，贯穿首页、阅读页和管理台 |
| 衬线大标题与等宽小标签 | 中文改用饱满的系统黑体与半粗标题，保留英文衬线标识和等宽编号；不依赖字体 CDN |
| 图像渐显、轻微动态 | 首页使用用户提供的完整楼梯合影，四周渐隐至纸色，轻降饱和并淡入微放大；手机和平板置于正文下方 |
| 绘图与文字交替排列 | 目录、旧照片、《岁月史书》、唱片和两段班会录音组成纪念册 |
| 夜间纸色和减少动态效果 | 日夜模式记忆、系统偏好回退；`prefers-reduced-motion` 时停用动画 |

原花园插画保留在素材目录，其 MIT 许可与修改说明见 [第三方素材说明](THIRD_PARTY_NOTICES.md)。书本、唱片和花形站点图标为本站绘制。图片、图标和样式均可本地读取。

首页展示图 `assets/media/graduation-staircase.webp` 由用户提供的 `微信图片_20261018230050_1470_13.jpg` 导出，保留完整人物和楼梯背景，原图不改动。色调与四边渐隐由 CSS 实现，夜间模式降低照片亮度；减少动态偏好下禁用入场与指针位移。

## 字体与字号

中文优先采用苹方、微软雅黑、Noto Sans SC / CJK SC，Linux 可回退 Droid Sans Fallback。标题字重 600，正文 17px，语录 19px，主导航 15px，阅读页标题桌面 48px / 手机 40px。辅助文字同步放大，手机正文保持 17px；通过行距和留白保持长文阅读舒适。字体取自设备本地，无需下载字库。

## 文件职责

- `css/style.css`：设计变量、公共头尾、首页、正文、人物与评论、响应式布局。
- `css/admin.css`：管理台及正文编辑器的布局，复用公共设计变量。
- `js/site.js`：主题、导航、搜索展开、回忆分类标签、阅读页目录、回到页首、合影与唱片的轻量交互。
- `js/app.js`：静态全文索引搜索、方向键和回车操作、搜索结果无障碍状态。
- `assets/illustrations/`：本地 SVG，`assets/media/`：既有照片与录音。

首页用 `main` 和分区标题组织内容；阅读页保留 `.content-left` 和原有 `.entry` / `.quote` 标识，以支持在线编辑与逐条评论。后台页面沿用原有控件 ID，便于继续使用现有 API。

## 行为约定

搜索按钮展开输入框，键盘 `/` 也可直接搜索。方向键选择结果，回车打开，Esc 关闭并归还焦点。原有搜索隐藏条目的规则保留。

手机导航使用展开按钮；正文下方的章节目录可以折叠。顶部导航、页尾链接和栏目正文采用真实链接。`file://` 下可阅读、搜索和播放本地录音；需要数据库的留言、投稿及编辑通过 Node 服务访问。

所有动画都是增强效果，正文不会因 JavaScript 未执行而隐藏。回忆分类有键盘切换。表单有明确标签和提交状态；夜间样式覆盖公共页面与后台。

`js/content.js` 发布 `window.MFContentReady`，逐条评论和正文交互等待覆盖内容加载完成。服务端先解析已保存的整页内容，再应用逐条覆盖、隐藏和新增。正文编辑 iframe 不注入逐条评论控件；保存时再次清理动态评论元素。已有页面覆盖仍存于同一 SQLite 表，不做删除或数据迁移。若此前在线保存了整个旧首页，覆盖层仍优先展示那一版；管理员可在保留历史版本的情况下选择「恢复默认」来采用新版首页布局。

音频使用浏览器原生控件和 `preload="none"`，不会在打开首页时下载整段录音。同一时间播放一段，唱片随播放转动；Node 静态服务支持 HTTP Range，因此可以拖动进度条。

## 验证

`npm run check` 校验页面链接、锚点、脚本语法和搜索目标。`npm test` 在隔离临时目录启动 Node/SQLite，分别以桌面与手机视口测试所有公共页面，以及搜索、主题、导航、留言、人物投稿、逐条编辑评论、管理台、正文编辑历史、旧地址跳转和音频分段请求。

运行命令及开发依赖安装见 [开发指南](DEVELOPMENT.md)。测试不会写入项目的 `data/` 或 `config.json`。
