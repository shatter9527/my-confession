# 第三方素材与设计参考

全站纸色、衬线排版和轻量交互参考 [Delineate](https://delineate.appautomaton.com/)，源码仓库为 [appautomaton/delineate](https://github.com/appautomaton/delineate)。参考日期：2026-10-17。

`assets/illustrations/garden-back.svg`、`garden-mid.svg`、`garden-front.svg` 提取自其首页的三层手绘花园，补充了独立 SVG 所需的命名空间、颜色与渐绘样式。SVG 全部本地提供，不依赖参考站运行。其他书本、唱片与花形图标为本项目绘制。

同一份许可保存在 `assets/illustrations/LICENSE-delineate.txt`，会随 Docker 镜像中的插画一起分发。
