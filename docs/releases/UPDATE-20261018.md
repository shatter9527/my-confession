## ⚠️ 升级时会自动迁移 config.json

第一次用新版 `server.js` 启动时，`config.json` 里的：

```json
"adminToken": "xxxx"
```

会被自动改写成：

```json
"adminTokens": [
  { "id": "a1", "name": "默认", "token": "xxxx", "createdAt": …, "lastUsedAt": 0 }
]
```

**旧口令不变，照样能登录**，不用重新记。只是想给令牌起名字，可以在审核台里新建一个名字叫得准的，再吊销「默认」。

迁移只在第一次发生，之后不会再动。

## 部署

### 方式 A：直接同步仓库（推荐）

服务器上如果已经 `git clone` 过：

```bash
cd /站点目录
cp config.json /tmp/config.json.bak        # 先留一份
git pull
cp /tmp/config.json.bak config.json        # 仓库里没有它，拉完补回来
systemctl restart confession
```

没有 git 的话：仓库首页 → `Code` → **Download ZIP** → 解压后把 `pages/`、`js/`、`css/`、`server.js`、`index.html` 覆盖上去。

### ⚠️ 两个文件永远不要覆盖

| 文件 | 原因 |
|---|---|
| `config.json` | 这台服务器自己的管理员口令 |
| `data/app.db` | 线上真实数据 |

`.gitignore` 已经把这两个排除了，正常 `git pull` 不会碰到它们。

### 重启

```bash
systemctl restart confession
# 或
pkill -f "node server.js" && cd /站点目录 && nohup node server.js > server.log 2>&1 &
```

## 管理员与令牌

令牌存在 **`config.json` 的 `adminTokens`** 数组里，一人一条：

```json
"adminTokens": [
  { "id": "a1",    "name": "默认", "token": "57c7fb…cba", "lastUsedAt": 1792… },
  { "id": "ax9k2", "name": "李四", "token": "c46158…39e2", "lastUsedAt": 0 }
]
```

- **加人**：审核台 →「管理员」→ 填名字 → 生成新令牌。完整令牌**只显示这一次**，复制给他
- **吊销**：点对应行「吊销」，那个人立刻失去后台权限，其他人不受影响
- **不能吊销自己**：正在用的那把会被拦住（防止把自己锁在门外）
- **最近使用**：判断谁还在用、谁已经废了

令牌列表只显示前后各 4 位，完整值只有生成那一刻可见。

## 怎么用

### 审核台

```
https://class1.ventiihan.top/pages/admin.html
```

- **审核开关**：词条 / 评论 / 留言
- **待审核区**：新增词条、删除申请、评论，各一栏
- **新增词条**：管理员直接上架
- **人物册**：每行「编辑」可改名字/分类/描述
- **全部评论 / 留言板**：隐藏、恢复、彻底删除

### 正文编辑

```
https://class1.ventiihan.top/pages/admin-content.html
```

1. 粘口令 → 载入
2. 下拉选页面（带「已改过」= 有覆盖）
3. 正文区出现虚线框，**点进去直接改字**
4. 「保存」→ 立刻对所有访客生效
5. 「恢复默认」→ 回到 HTML 原文
6. 「历史版本」→ 每次保存留一版，可回滚

编辑范围是 `.content-left` 那一块（标题、导语、正文条目、表格）。导航和页脚不在里面。

> 可编辑页面是**启动时扫盘自动发现的**（文件里含 `content-left` 就算），所以以后页面怎么挪位置都不用改代码。`admin`、`people-*`、`1.5*`、备份目录、`历史记录/` 会被自动排除。

## 回滚

```bash
git revert HEAD --no-edit
systemctl restart confession
```

数据不受影响：新表是自动建的，旧表结构没改。

## 常见问题

**Q：保存了正文，页面没变化？**
该页缺少 `<script src="/js/content.js"></script>`。`git pull` 之后应该都有了，可以用 `grep -r 'js/content.js' pages/ | wc -l` 确认。

**Q：`/api/settings` 里没有 commentsModerated？**
文件没换或服务没重启。

**Q：改坏了怎么办？**
正文编辑页点「恢复默认」或「历史版本」；代码层面 `git revert`。
